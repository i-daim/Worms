## Projet jeu Worms 

## Description
Projet universitaire réalisé dans le cadre du cours de Programmation Orientée Objet et le cours de Conduite de Projet.  
Ce projet consiste à développer un jeu inspiré de Worms.
Worms est un jeu de stratégie et de placement qui consiste à l'affrontement de plusieurs joueurs en tour par tour. Les joueurs incarnent une équipe de vers armés dans un environnement totalement destructible.

## Installation
- Première étape : Ouvrir le terminal et exécutez

    git clone https://moule.informatique.univ-paris-diderot.fr/daimi/aliens.git
- Deuxième étape : Se déplacer dans le dossier du projet  

    cd aliens
- Troisième étape : Compiler le projet avec Maven  
    mvn compile
- Quatrième étape : Lancer le jeu    
    mvn exec:java -Dexec.mainClass="main.Main"
